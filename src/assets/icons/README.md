# Иконки

Поместите PNG-иконки в эту папку.

## Использование в компонентах

```vue
<template>
  <!-- Локальный импорт -->
  <img src="@/assets/icons/my-icon.png" alt="Icon" class="w-5 h-5" />
</template>
```

## Текущий набор

Пока иконки не добавлены — используется временный набор SVG-иконок
встроенных прямо в компоненты (inline SVG).

Для замены на PNG:
1. Экспортируйте иконки из Figma в PNG
2. Поместите файлы в эту папку
3. Замените inline-SVG на `<img>` с нужным src
